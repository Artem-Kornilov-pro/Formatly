# Formatly frontend

React + TypeScript + Vite. Upload flow, job status, and profile selection UI.

```
npm install
npm run dev      # dev server on :5173
npm run test     # vitest
npm run lint     # oxlint
npm run build    # production build
```

`VITE_API_URL` (see `.env.example`) points it at the backend; defaults to `http://localhost:8000`.
